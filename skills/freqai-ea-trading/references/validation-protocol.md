# EA 驗證協議（事前登記）

本檔在任何 EA 回測之前寫好並推上 GitHub（見 git 歷史的時間戳）。之後只能新增結果，不能改這裡的期間與門檻；若要改，必須寫明原因並把那個 EA 視為新版本、重新驗證。

## 期間

| 用途 | BTC / ETH | SOL | 說明 |
|---|---|---|---|
| **D 研發期**：設計規則、看圖、調參 | 2021-06-01 → 2024-12-12 | 2021-06-01 → 2024-12-12 | 唯一可以反覆跑的期間 |
| **V1 事前樣本外**（從未回測過） | 2018-06-01 → 2021-06-01 | — | 含 2018 熊市、2019 反彈、2020 新冠崩盤、2020–21 牛市、2021-05 崩盤。SOL 上市太晚，無法做 |
| **V2 事後樣本外** | 2024-12-12 → 2026-11-01 | 2024-12-12 → 2026-11-01 | EA 從未在此期間測過；但網格策略研究時看過這段行情，誠實標示 |
| **V3 移轉測試**（只給 SOL） | — | AVAX、NEAR、DOT、ADA、LINK、DOGE，2021-09-01 → 2026-11-01 | 用 SOL 的凍結參數原封不動跑 6 個沒研究過的高波動幣，檢查邏輯是否只是貼合 SOL |
| **V4 穩健度**（研發期內） | 每個調過的參數 ±25%（一次動一個）；每邊手續費 0.20% | 同左 | |

V1、V2、V3 各只跑一次，參數在跑之前凍結並推上 GitHub。

## 共同設定

Binance 現貨、只做多、每邊手續費 0.10%（V4 另測 0.20%）、起始 10,000 USDT、Freqtrade 2026.10 + FreqAI（purged walk-forward，180 天訓練、30 天重訓）、1h K 線訊號、15m 細節 K 線模擬停損。最大回撤一律用盯市權益（逐小時，含未平倉）。

## 通過門檻（全部符合才算「驗證通過」）

**BTC、ETH**

1. V1 總報酬 > 0
2. V1 盯市最大回撤 < 同期買入持有最大回撤的 50%
3. V1 獲利因子（毛利 ÷ 毛損，扣費後）≥ 1.3，且交易 ≥ 15 筆
4. V2 報酬 > 同期買入持有報酬，且 V2 盯市最大回撤 ≤ 30%
5. V4：研發期內 ≥ 75% 的參數擾動版本仍獲利；每邊 0.20% 手續費下研發期仍獲利

**SOL**

1. V3：6 個幣中 ≥ 4 個獲利，且 6 個幣平均報酬 > 0
2. V3：6 個幣平均盯市最大回撤 < 它們買入持有最大回撤平均值的 50%
3. 研發期 SOL 本身獲利因子 ≥ 1.3
4. V2 同 BTC/ETH 第 4 條
5. V4 同 BTC/ETH 第 5 條

未通過的 EA 照實回報，不在驗證期間上調參補救。
