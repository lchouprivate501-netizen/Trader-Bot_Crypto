# 合約 EA 設計與研發紀錄

協議：[`futures-validation-protocol.md`](futures-validation-protocol.md)（commit 810c42f，在任何合約 EA 回測之前推上 GitHub）。以下所有數字都只用研發期 D（2021-06-01 → 2024-12-12）、Binance USDT-M 永續、每邊手續費 0.05%、含資金費。驗證期間在參數凍結前一次都沒跑過。

## 架構

`FuturesEABase`（`user_data/strategies/FuturesEABase.py`）＝ 現貨 EA 的多單（`EABase`，參數不變）＋ 對稱的空單 ＋ 逐倉保證金：

- **空單進場**：收盤跌破前 `s_breakout_h` 小時最低點，且價格在空單趨勢 EMA 帶之下、EMA 比 `s_slope_h` 小時前低（下降中）；ETH 另需 BTC 處於空頭（BTC 在其 100 日 EMA 帶之下）。
- **空單出場**：吊燈停損（進場後最低價 + `s_trail_k` × 日波動，只往下移）、收盤回到 EMA 帶之上（`trend_off`）、ETH 在 BTC 轉多時（`risk_on`）。
- **部位**：與多單相同的固定風險公式，名目 ≤ 權益 95%；槓桿不放大部位。
- **槓桿**：讓清算價距離 ≥ 2 倍初始停損距離的最大整數（1–3 倍），只減少佔用的保證金。研發期所有回測 0 次強平。
- **停損上限**：價格停損距離最多 30%（同現貨 EA 的 −30% 硬停損），與槓桿無關。

### 圖上看到的

TradingView 研究圖（`scripts/tv_research.py`，空單以橘色箭頭標示）：

1. 賺錢的空單幾乎都在真正的熊市第一段下跌：2021-12 → 2022-02、2022-04 → 06（Luna）、2022-11（FTX）。
2. 虧錢的空單是「上升趨勢中的回檔」：價格短暫跌破 EMA，但 EMA 本身還在往上（2023 整年、2024 的幾次回檔），以及崩盤後在最低點附近追空（例如 SOL 2024-08-05 直接打到 30% 停損）。
3. 熊市反彈又快又猛：10 倍日波動的寬停損會把一段下跌的利潤整段吐回去。

### 凍結的設定

三個幣共用同一個空單結構，只有跌破回看期不同，避免每個幣各自過度擬合：

| | 空單趨勢 EMA | EMA 下降 | 跌破回看 | 空單停損 | 空單風險 |
|---|---|---|---|---|---|
| BTCFuturesEA | 2400h（= 多單） | 720h | 360h | 3 倍日波動 | 10%（= 多單） |
| ETHFuturesEA | 1200h（= 多單），BTC 空頭才做空 | 720h | 360h | 3 倍日波動 | 10% |
| SOLFuturesEA | 1200h（= 多單） | 720h | 480h | 3 倍日波動 | 10% |

### 研發期就看得到的風險（驗證前寫下）

- **BTC 的空單很脆弱**：只在跌破 360h 附近賺錢，480h 以上就轉虧；研發期只有一段真正的熊市（2022），樣本少。
- **SOL 的 3 倍停損是尖峰**：2.5 / 3.5 倍時空單只剩小賺或虧損。
- **ETH 最穩**：周圍所有組合的空單都賺錢。
- 合約的多單一定比現貨多付資金費；牛市資金費高時，合約 EA 可能跑輸現貨 EA。
- 研發期 2021 年是三個幣合約 EA 的最差年份（2021 下半年多空來回被洗）。
